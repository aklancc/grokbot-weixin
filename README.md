# grokbot-weixin

Bridge WeChat (Weixin) to Grok Bot routines.

A small always-on service that logs in to a WeChat bot account via the Weixin iLink Bot API (the same backend used by Tencent's official [openclaw-weixin](https://github.com/Tencent/openclaw-weixin) plugin), forwards inbound messages to a Grok Bot webhook routine, and sends the routine's replies back to WeChat.

Status: work in progress.
